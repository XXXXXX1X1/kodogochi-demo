# kodogochi-demo

Тестовый репозиторий для показа [Кодогочи](https://github.com/XXXXXX1X1/kodogochi).

Сборка проверяет одно: в файле `status.txt` написано `ok`.

- Сломать сборку: замените `ok` на `fail` и сделайте коммит в `main`.
- Починить: верните `ok`.
- Грустный питомец: откройте PR и не делайте ревью.
